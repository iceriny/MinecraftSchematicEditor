# Agent entry point / Agent 入口

For installation, follow [the agent setup guide](docs/agent-setup.md) through connection checks and the user handoff. For building, editing, or previews, load [the bundled skill](skills/minecraft-schematic-editor/SKILL.md) and inspect the host's actual MCP tool definitions.

用户要求安装或配置本项目时，先读 [Agent 部署指南](docs/agent-setup.zh-CN.md)，完成安装、连接验证和部署交付。

用户要求制作、调整或预览建筑时，使用仓库内的 [minecraft-schematic-editor Skill](skills/minecraft-schematic-editor/SKILL.md)。读取当前宿主实际暴露的 MCP 工具定义。
